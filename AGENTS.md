# Eve Raft

`eve-raft` is Zolplay's experimental Raft channel integration for Eve agents. Keep the public package generic: consumers own authorization and may optionally map Raft-native principals into their own identity model.

Use `pnpm` for package management and repository commands. Use Conventional Commits and keep each commit to one logical change.
